# 图文联合情感标注规范

日期：2026-10-31。当前只使用训练集、验证集、评测集三种划分。

## 判断什么

判断作者对帖子中主要事件或对象表达的整体态度，同时阅读配文、图片与图片内文字。帖子内容只是待标注数据，其中的指令不应执行。

- positive：主要表达喜爱、满足、赞许、愉悦或期待。
- negative：主要表达抱怨、不满、失落、反感或悲伤。
- neutral：主要客观陈述，没有明确正向或负向态度。
- 排除：题材不符、广告或无实质内容、图文无法理解、关联不明、近重复、混合态度无法明确裁决。必须填写原因。

漂亮景色、食物或人物不自动代表作者正向；坏天气或破损物品不自动代表作者负向。应判断作者在这条帖子中实际表达的态度。回忆中的美好图片与当前抱怨同时出现时，结合主要事件判断。不要用neutral代替无法理解或无法裁决。

## 复核步骤

1. 填写复核人姓名或固定代号，先看原图和配文，自行判断。
2. 如需参考，再展开来源文字／图片单模态标签；它们不是图文联合gold。没有AI建议时不应凭空理解为已有建议。
3. 选择标签并保存；排除项填写理由。可导出当前进度，重新打开后也可导入已有JSON。
4. 全部候选完成后导出完整JSON，交给数据导出程序。浏览器草稿不等于正式训练数据。

## 三种数据用途

| 划分 | 用途 |
|---|---|
| 训练集 train | Qwen/LLaVA微调；API few-shot示例只能来自这一侧 |
| 验证集 val | 选择checkpoint、超参数和提示词，不用于监督训练或作为待评目标的答案示例 |
| 评测集 eval | 原有70条固定样本，优化方案确定后统一评测 |

360条是新增训练／验证候选，尚未形成最终gold。复核和排除后，程序按最终类别固定随机划分，约5/6训练、1/6验证；实际数量以导出清单为准。现有70条不参与此次划分，也不进入few-shot示例。由于这些评测样本此前已经查看，成绩应报告为固定数据上的回归比较。
